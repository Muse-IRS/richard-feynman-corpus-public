# Richard Feynman Corpus — Public

Public, versioned projection of the **Richard Feynman Corpus Research Lab**.

The repository exposes source-verifiable bibliography, chronology, provenance, scientific mappings and reproducible public artifacts about the work of **Richard P. Feynman (1918–1988)**.

It is intentionally **not** a mirror of the private research repository.

## Public purpose

Provide an inspectable public corpus that distinguishes:

```text
SOURCE
!= INTERPRETATION
!= TRANSCRIPTION
!= POSTHUMOUS EDITION
!= SECONDARY ATTRIBUTION
```

and preserves uncertainty rather than converting incomplete metadata into certainty.

## Public/private boundary

Private authority:

`Muse-IRS/richard-feynman-corpus-research-lab`

Projection rule:

```text
PRIVATE RESEARCH AUTHORITY
  -> QUALIFY
  -> MINIMIZE
  -> PUBLIC ARTIFACT
```

The public repository does not expose private ingestion logic, internal matching heuristics, unresolved private working notes or any method whose publication has not been explicitly approved.

## Scientific status

The corpus may contain verified bibliographic records, documented relations and explicitly marked uncertainties.

```text
PUBLIC != PEER_REVIEWED
CITATION_COUNT != VALIDATION
ANALOGY != IDENTITY
SIMILARITY != HISTORICAL_LINEAGE
UNKNOWN = VALID_RESULT
```

## New Feyman Graph boundary

Any future comparison with **New Feyman Graph / New Feynman Graph** is kept separate from the historical corpus.

A public comparison may be published only after an explicit discriminant is defined. Historical Feynman work is never presented as validating a new model merely because a structural resemblance exists.
