# Public publication policy

## Purpose

This repository exposes only bounded, source-verifiable public artifacts derived from the private research authority:

`Muse-IRS/richard-feynman-corpus-research-lab`

## Promotion rule

```text
PRIVATE RESEARCH AUTHORITY
 -> QUALIFY
 -> MINIMIZE
 -> PUBLIC ARTIFACT
```

No private method is copied automatically into this repository.

## Required public properties

Every published record or relation must preserve, where applicable:

- source identifier;
- source URL or stable reference;
- retrieval or verification date;
- document/work identifier;
- provenance class;
- uncertainty/conflict status;
- version lineage when known.

## Public locks

```text
PUBLIC != PEER_REVIEWED
SOURCE_LINK != ENDORSEMENT
CITATION_COUNT != VALIDATION
TRANSCRIPT != ORIGINAL_EVENT
POSTHUMOUS_EDIT != ORIGINAL_PUBLICATION
ANALOGY != IDENTITY
SIMILARITY != HISTORICAL_LINEAGE
UNKNOWN = VALID_RESULT
```

## Third-party material

Do not republish scans, abstracts, figures, archival images, publisher text or other third-party material unless the right to do so is clear.

Prefer metadata, identifiers, short factual descriptions, links and original project analysis.

## New Feyman Graph

Historical Feynman material and New Feyman Graph remain separate research layers. Any public comparison requires an explicit discriminant and must state whether the result is relation, analogy, no relation or unknown.
